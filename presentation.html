Structured Output
Agent 02·03·04 — Extract·Classify·Deadline
1회 통합 호출
HTML을 LLM에 전달할 때 응답 형식을 JSON 스키마로 강제. LLM이 자유롭게 텍스트를 쓰지 않고 지정된 필드만 채워 반환
// 요청 시 response_format 지정
"response_format": {
  "type": "json_schema",
  "schema": {
    "title": "string",
    "summary": "string",
    "deadline": "YYYY-MM-DD | null",
    "category": "창업|취업|장학금|..."
  }
}
→ LLM이 HTML을 읽고 위 필드를 채운 JSON만 반환
→ 파싱·분류·날짜 추출을 단 1번의 호출로 처리
⚡
Function Calling
Agent 05 — Calendar Agent
사용자 선택 시
LLM에게 사용할 수 있는 함수 목록을 미리 전달. LLM이 공지 내용을 보고 필요한 함수와 파라미터를 스스로 결정해 호출
// 함수 정의를 tools로 전달
"tools": [{
  "name": "create_calendar_event",
  "parameters": {
    "title": "string",
    "start_date": "YYYY-MM-DD",
    "end_date": "YYYY-MM-DD"
  }
}]
→ LLM이 공지 요약을 읽고 날짜·제목을 추론해 파라미터 자동 완성
→ 앱이 반환된 파라미터로 Google Calendar API 직접 호출
